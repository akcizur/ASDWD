# NANAS Blog

Minimalistický blog postavený na Reactu 18, Vite 5 a Tailwindu 3. Obsah je připraven pro automatizovaný Markdown publishing s whitespace-first typografií.

## Funkce

- Light / dark mode s FOUC prevencí
- 4 zobrazení seznamu: list, grid, magazine, compact
- Nastavitelná šířka obsahu (38 / 48 / 64 rem)
- Nastavitelná velikost písma (sm / base / lg)
- Nastavitelná hustota mezer (compact / airy)
- Přístupnost: aria atributy, klávesnice, Esc, scroll lock
- Persistence přes localStorage

## Instalace

    npm install
    npm run dev

## Build

    npm run build
    npm run preview
